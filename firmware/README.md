# Firmware

Microcontroller code: SpO₂ / heart-rate sensing, blood pressure measurement, and the High / Medium / Low triage logic. Must run fully offline on battery.

**Hardware revision supported:** _none yet_. Update this line whenever a board revision changes pins, I²C addresses or timing (see the ECO process in `docs/release.md`).

Branch names: `fw/<what>`. Commit messages: `fw(<module>): <what>`.
